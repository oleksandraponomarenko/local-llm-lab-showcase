# Planned checks for adaptation

Oleksandra specified that adaptation should be tested with comparable tasks and re-evaluated when the underlying model changes. She also approved a requirement to keep the components needed for evaluation and adaptation in readable formats that can be carried between models.

| Proposed comparison | What it would show |
|---|---|
| Record a baseline with the initial configuration. | How that configuration performs on the agreed tasks before adaptation. |
| Compare baseline and adapted configurations on the same tasks and criteria. | Which outcomes or behaviours change, and where the adapted version still falls short. |
| Repeat the comparison after changing the model. | Which results carry over and which change with the model. |

The lab is designing these checks. The public record here is a statement of the planned method. See the [progress snapshot](2026-11-20-lab-progress.md) for the stage reached at its cutoff.
